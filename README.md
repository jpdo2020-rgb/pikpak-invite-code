## 1. PikPak이란?

PikPak은 클라우드 기반 파일 저장 및 관리 서비스입니다.

주요 기능:
- 클라우드 파일 저장 및 관리
- 다양한 기기에서 파일 접근
- 동영상 스트리밍 기능
- 클라우드 다운로드 기능
- 파일 공유 기능

공식 홈페이지: https://mypikpak.com/

## 3. 초대 코드 입력 방법

1. PikPak 공식 홈페이지 또는 앱에 접속합니다.
2. 회원가입 및 로그인을 진행합니다.
3. 앱 내 초대 코드 입력 메뉴를 확인합니다.
4. 초대 코드를 입력합니다.
5. 혜택 적용 여부를 확인합니다.

※ 초대 코드 입력 가능 시간 및 조건은 서비스 정책에 따라 달라질 수 있습니다.

## 4. 주요 기능

| 기능 | 설명 |
|---|---|
| 클라우드 저장 | 파일을 온라인에 보관 |
| 동영상 재생 | 클라우드에 저장된 영상 재생 |
| 파일 관리 | 폴더 및 파일 관리 |
| 파일 공유 | 다른 사용자와 파일 공유 |
| 멀티 디바이스 | 여러 기기에서 이용 |
